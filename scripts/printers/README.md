# Scripts de Impressora

Esta pasta centraliza scripts de manutencao e debug de impressoras.

## Scripts

- `printerstest.js`: debug operacional (`summary`, `list`, `test-ip`, `imaging-debug`, etc.)
- `test_printer_module.js`: teste de integracao do modulo de impressoras

## Compatibilidade

Os caminhos antigos continuam funcionando:

- `scripts/printerstest.js`
- `scripts/test_printer_module.js`

Eles apenas redirecionam para os arquivos desta pasta.
